AmpSpread v9.8.4 — Third-party interfaces

Microsoft Windows: standard Win32, USB HID, SetupAPI, GDI and filesystem APIs. No Windows binary is redistributed.

MSI MPG Ai1600TS / Ai1300TS: only the supported USB PSU interface is used. The inherited v9.8.1 fan backend permits product identification, telemetry/alarm and fan configuration reads, fan-mode/target and Zero Fan writes, and the validated F1 save command. See PSU_FAN_CONTROL.md for protocol scope and limitations. No MSI binary is redistributed.

No NVIDIA, NVML or NVAPI driver integration is included. Historical generic GPU columns are offline file parsing only. No live HWiNFO or Afterburner shared-memory polling is included.

Go runtime and standard library: BSD-style license in licenses/GO-LICENSE.txt.
