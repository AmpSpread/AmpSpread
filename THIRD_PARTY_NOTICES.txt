AmpSpread v9.7.8 — Third-Party Interfaces
=========================================

Microsoft Windows
-----------------
AmpSpread uses standard Win32, HID, SetupAPI, GDI and file-system APIs supplied
by Windows. No Microsoft binary is redistributed by AmpSpread.

MSI MPG Ai1600TS / Ai1300TS
---------------------------
Live PSU monitoring is implemented through the PSU's USB HID interface. The
monitoring path has a compile-time allowlist for these fixed requests:

  FA/51  product identification handshake
  51/E0  telemetry snapshot
  51/C1  firmware alarm status

The opt-in fan preview also permits 51/41 and 51/42 reads, validated 50/41
mode/target requests and 50/43 zero-fan boolean requests. It excludes permanent
save (50/F1), arbitrary commands, firmware updates, voltage, protection and
power-limit settings. Protocol facts were inspected in MSI Center 2.0.74.0's
Power Supply Unit SDK 1.0.0.38. No MSI binaries are redistributed.
See docs/PSU_FAN_CONTROL.md.

Legacy log compatibility
------------------------
The offline CSV analyzer recognizes older AmpSpread/HWiNFO/Afterburner-compatible
column names so historical logs remain readable. AmpSpread v9.7.8 contains no
live HWiNFO or MSI Afterburner shared-memory polling code.

NVIDIA NVML (optional)
----------------------
The optional board-power reader dynamically uses the installed, signed Windows
System32 nvml.dll. No NVIDIA binary, SDK header or third-party binding is
redistributed. The resolved entry points are nvmlInit_v2, nvmlShutdown,
nvmlDeviceGetCount_v2, nvmlDeviceGetHandleByIndex_v2 and nvmlDeviceGetPowerUsage.
Reference: https://docs.nvidia.com/deploy/nvml-api/nvml-api-reference.html
